# Sumar un repo a AllForOne

Gracias por querer sumar. El catálogo tiene un criterio simple: **que exista, que sirva y que se pueda instalar**.

## Qué entra

- Skills, plugins, MCPs, CLIs, librerías o apps que sirvan para trabajar con Claude Code u otros agentes de código.
- Repos públicos, no archivados y con un README que explique cómo instalarlos.
- Tips concretos (un comando, un patrón, un prompt) que se puedan usar sin comprar nada.

## Qué no entra

- «Comentá X y te lo mando» sin un repo real detrás.
- Repos archivados, vacíos o que solo redirigen a un producto pago.
- Cualquier cosa que pida credenciales para «probarla».

## Cómo proponerlo

Abrí un issue con la plantilla **«Sumar un repo»** y completá:

1. El link del repo (`owner/repo`).
2. Dónde lo viste (reel, video, post), si aplica.
3. Para qué te sirvió, en una frase.

Cada propuesta se verifica con GitHub (existe, estrellas, último push, README) antes de sumarse. El README se genera solo: por eso no hace falta mandar un PR que lo edite a mano.
